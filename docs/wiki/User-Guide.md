# User Guide

## Install

Use a release build (see README "Installing a release"), or build from source. Manual install paths are
in the README Troubleshooting section.

## Use it

1. Drop a WAV, AIFF, FLAC, MP3, OGG file, or a `.texture` preset onto the left panel, or click to browse.
2. Play a chord. Samples default to C3 (MIDI 60). Each sample panel has its own root-note and fine-cent
   controls. TUNE is a separate whole-semitone offset.
3. Turn **MORPH**. Low values stay close to the source; high values diffuse it.

Other controls: ADSR per voice (1.2 s default release), grain TUNE, REVERSE and SHIMMER, reverb, chorus,
saturation and high shelf. Ctrl/Cmd+Z and Ctrl/Cmd+Shift+Z (or Ctrl/Cmd+Y) undo and redo control
changes, randomise, reset, preset load and A/B recall. MIDI: omni, velocity to amplitude, ±2 semitone
bend, sustain pedal, CC learn on every control. Press F1 in the plugin for the manual.

## Free and Pro

Free is the full engine with no CPU limit, watermark or time limit. Pro adds the preset browser,
dual-layer, the MORPH LFO and WAV export. Activation is offline (a key derived from your email); see
the README "Free vs Pro" section.
